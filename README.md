# 워드퀘스트 (Word Quest)

게임처럼 스테이지를 깨며 레벨업하는 영어 단어 앱. 설치·빌드 없이 파일만으로 동작하는 웹앱(PWA)입니다.

## 실행

```bash
cd word-quest
python3 -m http.server 8090
# 브라우저에서 http://localhost:8090 열기
```

`file://`로 직접 열면 동작하지 않습니다(ES 모듈 때문). 꼭 위처럼 서버로 여세요.
학습 기록은 브라우저의 localStorage에 저장되므로 **같은 주소로 열어야** 이어집니다.

## 진행 방식

- 레벨 4개(새싹 → 새잎 → 나무 → 숲) × 스테이지 4개 × 단어 8개 = 128단어
- 스테이지: 단어 카드로 학습 → 퀴즈 16문제(단어당 2문제) → **80% 이상**이면 클리어(★1~3)
- 스테이지 4개를 모두 깨면 **레벨 테스트**(16문제, 80% 이상)가 열리고, 통과하면 다음 레벨이 열림
- 퀴즈 유형: 뜻 고르기 / 듣고 고르기 / 빈칸 채우기 / 단어 고르기 / 스펠링 쓰기
- 틀린 단어는 같은 세션에서 다른 유형으로 다시 물어봄(최대 2번)
- **복습**: 망각곡선 방식. 맞히면 1일 → 2 → 4 → 7 → 15 → 30일로 간격이 늘고, 틀리면 처음부터
- **오답노트**: 틀린 단어가 자동 등록되고, 복습/연습에서 연속 3번 맞히면 졸업
- 연속 학습일(스트릭), 일일 목표, 14일 활동 그래프, 기억 단계 통계, 백업 내보내기/불러오기

## 단어 추가

`js/data.js`의 `RAW`에 스테이지를 추가하거나 단어를 넣으면 됩니다.

```js
['borrow', 'v', '빌리다', 'Can I *borrow* your pen?', '펜 좀 빌려도 될까?'],
//  영단어   품사   뜻       예문(대상 단어를 *로 감쌈)            예문 해석
```

- 예문 속 `*...*`는 영단어와 **똑같은 형태**여야 합니다(빈칸 퀴즈에 사용).
- 뜻(ko)은 단어마다 달라야 합니다(오답 보기가 겹치지 않도록).
- 수정 후 `node tests/test.mjs`로 검증하세요(단어 수, 중복, 예문 표시, 문제 생성, 복습 간격, 잠금 규칙 등).
- 스테이지는 8단어씩 묶는 것을 전제로 합니다(퀴즈 16문제). 다른 개수를 쓰려면 `tests/test.mjs`의 기대값도 바꾸세요.

## 폰에 설치하기

PWA 설치와 서비스워커는 **HTTPS(또는 localhost)** 에서만 동작합니다. 같은 와이파이의 `http://192.168.x.x:8090`으로는 열리지만 설치는 안 됩니다.
폰에 설치하려면 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 폴더를 그대로 올리세요. 파일을 고쳤다면 `sw.js`의 `VERSION`을 올려야 기존 사용자에게 반영됩니다.

## 알림의 한계

브라우저 알림은 앱이 열려 있거나 백그라운드에서 살아 있을 때만 울립니다. 앱이 완전히 꺼진 상태에서 정해진 시각에 알림을 보내려면 푸시 서버(또는 별도 알림 연동)가 필요합니다. 홈 화면 앱 아이콘에는 복습 대기 개수가 배지로 표시됩니다(지원 기기).

## 파일 구조

```
index.html, manifest.webmanifest, sw.js
css/style.css
js/data.js    레벨·스테이지·단어 데이터
js/srs.js     간격 반복(복습 일정)
js/quiz.js    문제 생성·채점
js/store.js   저장소(진행도·스트릭·잠금)
js/tts.js     발음(Web Speech API)
js/notify.js  복습 알림·배지
js/app.js     화면·라우팅·세션 진행
tests/test.mjs
```
