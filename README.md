# 워드퀘스트 (Word Quest)

게임처럼 스테이지를 깨며 레벨업하는 외국어 단어 앱 (영어 / 일본어). 설치·빌드 없이 파일만으로 동작하는 웹앱(PWA)입니다.

## 실행

```bash
cd word-quest
python3 -m http.server 8090
# 브라우저에서 http://localhost:8090 열기
```

`file://`로 직접 열면 동작하지 않습니다(ES 모듈 때문). 꼭 위처럼 서버로 여세요.
학습 기록은 브라우저의 localStorage에 저장되므로 **같은 주소로 열어야** 이어집니다.

## 진행 방식

- **언어 트랙 2개**: 홈 화면 상단 탭에서 전환. 각자 독립된 레벨·진행도·잠금을 가짐
  - 🇬🇧 영어: 레벨 4개(새싹 → 새잎 → 나무 → 숲), 928단어
  - 🇯🇵 일본어: JLPT 급수 — N5(192단어, 24스테이지), N4(64단어, 8스테이지). 추후 N3~N1 추가 예정
- 스테이지: 단어 카드로 학습 → 퀴즈 16문제(단어당 2문제) → **80% 이상**이면 클리어(★1~3)
- 스테이지를 모두 깨면 **레벨 테스트**(16문제, 80% 이상)가 열리고, 통과하면 같은 언어의 다음 레벨이 열림(언어끼리는 서로 영향 없음)
- 퀴즈 유형: 뜻 고르기 / 듣고 고르기 / 빈칸 채우기 / 단어 고르기 / 스펠링 쓰기 / **빈칸 쓰기** / **한자 읽기**(일본어) / **활용형**(일본어 동사)
  - 스펠링 쓰기는 영어는 철자 그대로, 일본어는 **로마자**로 입력(IME 없이도 가능, si/shi·tu/tsu 같은 표기 차이 허용)
  - 빈칸 쓰기(말해보카식): 예문 빈칸에 단어를 직접 입력. 일본어는 한자·히라가나·가타카나·로마자 모두 정답이고, 로마자를 치면 가나로 바로 보여줌
  - 한자 읽기: 한자 표기만 보고 읽는 법(히라가나) 고르기. 가나뿐인 단어는 뜻 고르기로 대체
  - 활용형: 동사의 ます형·て형·ない형·た형 고르기. 오답 보기는 자주 틀리는 형태(行いて, 帰ます, 買あない 등)로 만들고, 틀리면 규칙을 알려줌
- 일본어 단어 카드에 동사 활용표 표시, 설정에서 **후리가나 끄기**(가려지고 눌러야 보임)
- 틀린 단어는 같은 세션에서 다른 유형으로 다시 물어봄(최대 2번)
- **복습**: 망각곡선 방식. 맞히면 1일 → 2 → 4 → 7 → 15 → 30일로 간격이 늘고, 틀리면 처음부터
- **오답노트**: 틀린 단어가 자동 등록되고, 복습/연습에서 연속 3번 맞히면 졸업
- 연속 학습일(스트릭), 일일 목표, 14일 활동 그래프, 기억 단계 통계, 백업 내보내기/불러오기

## 단어 추가

`js/data.js`의 `RAW`(영어)/`RAW_JA`(일본어)에 스테이지를 추가하거나 단어를 넣으면 됩니다.

```js
// 영어
['borrow', 'v', '빌리다', 'Can I *borrow* your pen?', '펜 좀 빌려도 될까?'],
//  영단어   품사   뜻       예문(대상 단어를 *로 감쌈)            예문 해석

// 일본어
['食べる', 'たべる', 'taberu', 'v', '먹다', '朝ご飯を*食べる*。', '아침밥을 먹는다.'],
//  표제어(한자/가나)  읽기(후리가나)  로마자    품사  뜻   예문(표제어를 *로 감쌈)   예문 해석
```

- 예문 속 `*...*`는 표제어와 **똑같은 형태**여야 합니다(빈칸 퀴즈에 사용).
- 뜻(ko)은 같은 언어 안에서 겹치는 게 없어야 합니다(오답 보기는 같은 언어에서만 뽑음). 새 단어를 쓸 때는 `node -e "import('./js/data.js').then(({ALL_WORDS}) => console.log(ALL_WORDS.map(w=>w.ko).join('\n')))"`로 기존 뜻 목록을 뽑아 겹치는지 먼저 확인하세요.
- 새 레벨(JLPT 급수 등)을 추가할 때는 레벨 헤더에 `lang: 'ja'`, `jlpt: 'N4'`처럼 급수 라벨용 필드를 꼭 넣으세요(`labelOf()`가 이걸로 "N4" 배지를 만듭니다).
- 일본어 동사는 활용형이 자동 생성됩니다. る로 끝나고 앞이 い·え단인데 5단인 동사(帰る·入る 등)는 `js/conj.js`의 `GODAN_RU`에 넣으세요. 로마자는 변환하면 읽기와 같아야 합니다(테스트가 확인).
- 수정 후 `node tests/test.mjs`로 검증하세요(단어 수, 중복, 예문 표시, 문제 생성, 복습 간격, 잠금 규칙 등).
- 스테이지는 8단어씩 묶는 것을 전제로 합니다(퀴즈 16문제). 다른 개수를 쓰려면 `tests/test.mjs`의 기대값도 바꾸세요.

## 폰에 설치하기

PWA 설치와 서비스워커는 **HTTPS(또는 localhost)** 에서만 동작합니다. 같은 와이파이의 `http://192.168.x.x:8090`으로는 열리지만 설치는 안 됩니다.
폰에 설치하려면 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 폴더를 그대로 올리세요. 파일을 고쳤다면 `sw.js`의 `VERSION`을 올려야 기존 사용자에게 반영됩니다.

## 알림의 한계

브라우저 알림은 앱이 열려 있거나 백그라운드에서 살아 있을 때만 울립니다. 앱이 완전히 꺼진 상태에서 정해진 시각에 알림을 보내려면 푸시 서버(또는 별도 알림 연동)가 필요합니다. 홈 화면 앱 아이콘에는 복습 대기 개수가 배지로 표시됩니다(지원 기기).

## 파일 구조

```
index.html, manifest.webmanifest, sw.js
css/style.css
js/data.js    레벨·스테이지·단어 데이터
js/srs.js     간격 반복(복습 일정)
js/quiz.js    문제 생성·채점
js/kana.js    로마자→가나 변환(일본어 입력)
js/conj.js    일본어 동사 활용(ます·て·ない·た형)
js/store.js   저장소(진행도·스트릭·잠금)
js/tts.js     발음(Web Speech API)
js/notify.js  복습 알림·배지
js/app.js     화면·라우팅·세션 진행
tests/test.mjs
```
